🛡️ Guía Definitiva: Instalación Limpia de SafeLine WAF

Propósito: Proporcionar un método paso a paso, en español, para desplegar SafeLine WAF desde cero, asegurando la interfaz en inglés y evitando los errores de contraseña encontrados previamente. Diseñada para funcionar a la primera.

📋 Requisitos Previos Antes de empezar

Asegúrate de que tu servidor (VPS) cumpla con los siguientes requisitos mínimos:

  • Sistema Operativo: Linux (preferiblemente Debian o Ubuntu)
  • Arquitectura: x86_64 (debe soportar SSSE3)
  • Docker: Versión 20.10.14 o superior
  • Docker Compose: Versión 2.0.0 o superior
  • Recursos: 1 CPU, 1 GB RAM, 5 GB disco
🐳 Paso 0: Instalación de Docker y Docker Compose Requisito base

Si tu servidor no tiene Docker ni Docker Compose instalados, sigue estos pasos antes de continuar con la instalación de SafeLine. Si ya los tienes instalados, puedes saltar directamente al Paso 1.

Nota: El método recomendado es usar el repositorio oficial de Docker en lugar del paquete docker.io de la distribución, ya que este último suele estar desactualizado [citation:16][citation:11].

0.1. Actualizar el sistema e instalar dependencias

Actualiza los paquetes existentes e instala las herramientas necesarias para agregar el repositorio de Docker [citation:6][citation:17]:

sudo apt update && sudo apt upgrade -y
sudo apt install -y ca-certificates curl gnupg

0.2. Agregar la clave GPG oficial de Docker

Este paso asegura que los paquetes que descargues estén firmados y sean auténticos [citation:3][citation:4]:

sudo install -m 0755 -d /etc/apt/keyrings
curl -fsSL https://download.docker.com/linux/debian/gpg | sudo gpg --dearmor -o /etc/apt/keyrings/docker.gpg
sudo chmod a+r /etc/apt/keyrings/docker.gpg

Si usas Ubuntu, cambia debian por ubuntu en la URL de la clave GPG [citation:4][citation:8].

0.3. Agregar el repositorio de Docker

echo \
"deb [arch=$(dpkg --print-architecture) signed-by=/etc/apt/keyrings/docker.gpg] https://download.docker.com/linux/debian \
$(lsb_release -cs) stable" | sudo tee /etc/apt/sources.list.d/docker.list > /dev/null

Para Ubuntu, reemplaza debian por ubuntu en la URL [citation:6].

0.4. Instalar Docker Engine y Docker Compose

Ahora instala todos los componentes necesarios, incluyendo el plugin de Compose [citation:3][citation:6]:

sudo apt update
sudo apt install -y docker-ce docker-ce-cli containerd.io docker-buildx-plugin docker-compose-plugin

0.5. Habilitar e iniciar el servicio de Docker

sudo systemctl enable docker
sudo systemctl start docker

0.6. (Opcional pero recomendado) Configurar permisos de usuario

Por defecto, necesitas sudo para ejecutar comandos de Docker. Para evitar esto (y prevenir problemas de permisos con SafeLine), agrega tu usuario al grupo docker [citation:1][citation:6][citation:17]:

sudo usermod -aG docker $USER
newgrp docker
Advertencia de seguridad: Pertenecer al grupo docker equivale a tener privilegios de root, ya que permite montar el sistema de archivos del host. Úsalo con responsabilidad [citation:11][citation:16].

0.7. Verificar la instalación

Confirma que Docker y Docker Compose se instalaron correctamente [citation:1][citation:6]:

docker --version
docker compose version
sudo docker run hello-world

Si el comando hello-world imprime un mensaje de confirmación, la instalación fue exitosa.

¡Listo! Docker y Docker Compose están instalados. Ahora puedes continuar con el Paso 1 para instalar SafeLine WAF.
🧹 Paso 1: Limpieza Total del Entorno Anterior Limpieza

Para asegurar una instalación exitosa, eliminaremos cualquier rastro de intentos previos.

1. Detener y eliminar contenedores, redes y volúmenes de SafeLine

cd /data/safeline
sudo docker compose down --volumes --remove-orphans
Nota: Si el comando docker compose no se encuentra, prueba con docker-compose.

2. Eliminar el directorio de instalación

cd /
sudo rm -rf /data/safeline

3. Verificar que no queden volúmenes huérfanos de SafeLine

sudo docker volume ls | grep safeline

Si el comando anterior muestra algún volumen, elimínalo con sudo docker volume rm <nombre_del_volumen>.

📦 Paso 2: Instalación Manual Paso a Paso Instalación

Este método nos da control total y evita consumir recursos innecesarios.

2.1. Crear el Directorio de Instalación

sudo mkdir -p /data/safeline
cd /data/safeline

2.2. Descargar el Script de Docker Compose

sudo wget "https://waf-ce.chaitin.cn/release/latest/compose.yaml"

2.3. Crear el Archivo de Variables de Entorno (.env)

Este es el paso crítico para solucionar el error de autenticación de PostgreSQL y garantizar el idioma inglés.

sudo nano .env

Copia y pega exactamente el siguiente contenido dentro del editor:

SAFELINE_DIR=/data/safeline
IMAGE_TAG=latest
MGT_PORT=9443
POSTGRES_PASSWORD=MiClaveSegura2026
SUBNET_PREFIX=172.22.222
IMAGE_PREFIX=chaitin
ARCH_SUFFIX=
RELEASE=
REGION=-g
Explicación de las variables clave:
  • POSTGRES_PASSWORD: Debe ser una contraseña solo con letras y números. No uses caracteres especiales como {, }, @, #, $, etc., ya que romperían la URL de conexión y causarían el error password authentication failed o invalid userinfo.
  • REGION=-g: Esta variable es la que fuerza la instalación de la Edición Internacional (Inglés). Si se deja vacía, se instala la versión China.
  • IMAGE_PREFIX=chaitin: Se usa para descargar las imágenes desde Docker Hub, que suele ser más rápido para servidores fuera de China.

Guarda el archivo con Ctrl + O, luego Enter, y sal con Ctrl + X.

2.4. Levantar SafeLine

sudo docker compose up -d

Este proceso descargará las imágenes y arrancará los 7 contenedores. Puede tardar varios minutos.

2.5. Verificar el Estado de los Contenedores

sudo docker ps

Espera hasta que todos los contenedores (safeline-mgt, safeline-luigi, safeline-pg, etc.) muestren un estado Up estable (ej. Up 2 minutes (healthy)) y no Restarting.

🔑 Paso 3: Obtener las Credenciales de Acceso Credenciales

Una vez que los contenedores estén estables, genera el usuario y la contraseña para el panel de administración.

sudo docker exec safeline-mgt resetadmin
La terminal te mostrará un nombre de usuario (admin) y una contraseña generada aleatoriamente. Anótala inmediatamente, ya que no se volverá a mostrar.
🌐 Paso 4: Acceder a la Interfaz Web Acceso

Abre tu navegador y ve a la siguiente URL:

https://TU_IP_PUBLICA:9443

(Reemplaza TU_IP_PUBLICA con la IP de tu VPS, ej. https://162.243.163.116:9443).

  1. Acepta la advertencia de seguridad del navegador (certificado autofirmado) haciendo clic en "Avanzado" y luego en "Continuar a ... (no seguro)".
  2. Introduce el usuario (admin) y la contraseña que obtuviste en el Paso 3.
La interfaz ahora debería mostrarse completamente en inglés.
🛠️ Solución de Problemas (Troubleshooting) Errores comunes
❌ Error: password authentication failed o failed SASL auth (SQLSTATE 28P01)

Causa: El volumen de datos de PostgreSQL conserva una contraseña antigua que no coincide con la nueva en el archivo .env.

Solución: Ejecuta los siguientes comandos para eliminar el volumen de PostgreSQL y forzar su reinicialización:

cd /data/safeline
sudo docker compose down -v
sudo docker compose up -d

El flag -v es esencial aquí.

❌ Error: cannot parse ... invalid userinfo o net/url: invalid userinfo

Causa: La contraseña de POSTGRES_PASSWORD en el archivo .env contiene caracteres especiales que rompen el formato de la URL de conexión.

Solución: Edita el archivo .env y cambia POSTGRES_PASSWORD por una contraseña que contenga solo letras y números. Luego, aplica la solución del error anterior (docker compose down -v y docker compose up -d).

❌ Error: dial error (dial tcp ... connect: no route to host)

Causa: El firewall del sistema operativo está bloqueando la comunicación entre los contenedores de Docker en la red interna de SafeLine.

Solución: Permite el tráfico en la interfaz de red de Docker.

# Identifica el nombre de la interfaz (usualmente safeline-ce)
ip link show | grep safeline-ce

# Añade la interfaz a la zona de confianza del firewall (ejemplo con firewalld)
sudo firewall-cmd --permanent --zone=trusted --add-interface=safeline-ce
sudo firewall-cmd --reload

Si usas ufw o nftables, deberás añadir una regla similar para permitir todo el tráfico en la interfaz safeline-ce.

❌ La interfaz sigue en Chino

Causa: No se configuró correctamente la variable REGION en el archivo .env.

Solución: Asegúrate de que la línea REGION=-g esté presente y sin errores tipográficos en tu archivo .env. Si ya instalaste, puedes editar el archivo y reiniciar con docker compose up -d.

❌ No puedo acceder a la WebUI (ERR_CONNECTION_REFUSED)

Causa: El puerto 9443 no está abierto en el firewall de tu proveedor de nube (ej. DigitalOcean) o el contenedor safeline-mgt está inestable.

Solución:

  1. Verifica el contenedor: Ejecuta sudo docker ps y asegúrate de que safeline-mgt esté Up y no Restarting.
  2. Abre el puerto en el firewall del proveedor: Crea una regla de entrada (Inbound Rule) para el protocolo TCP en el puerto 9443.
  3. Verifica el puerto localmente: En el servidor, ejecuta curl -k -v https://127.0.0.1:9443. Si obtienes una respuesta, el problema es el firewall externo.
✅ Checklist de Verificación Final Comprobación
  • Docker y Docker Compose están instalados y funcionando.
  • El directorio /data/safeline fue eliminado y recreado.
  • El archivo .env contiene POSTGRES_PASSWORD con solo letras y números.
  • El archivo .env contiene REGION=-g para la versión en inglés.
  • El comando sudo docker ps muestra todos los contenedores en estado Up.
  • El puerto 9443 está abierto en el firewall de tu proveedor de nube.
  • Obtuviste y anotaste las credenciales con sudo docker exec safeline-mgt resetadmin.
  • Accedes a la WebUI en https://<IP>:9443 y ves la interfaz en inglés.

Siguiendo esta guía, la instalación de SafeLine WAF debe completarse sin contratiempos y con la interfaz en el idioma deseado.
